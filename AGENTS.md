# Akyat hackathon collaboration

This is an original three-hour UX hackathon build. Existing application code and assets from other Akyat repositories are out of scope. Use Codex for creation.

Read `docs/PRODUCT.md` before changing product behavior. Read `docs/ROLES.md` before choosing work. Carlos's Codex starts with `docs/CARLOS-START-HERE.md`.

## Ownership
- Marti's Codex owns app source, tests, dependencies, hosting, this file, and product decisions.
- Carlos's Codex owns `collaboration/carlos/`: pitch, narration, storyboard, copy proposals, and UX findings. Propose engineering changes there rather than modifying app source.
- Preserve the other person's work. On separate checkouts, pull before starting. Carlos uses a `carlos/pitch-video` branch and shares commits or a PR; merge only with Marti's approval.

## Demo boundaries
- Fictional departures and identities; simulated payments; browser-local state. No claim of official trail acceptance, genuine accreditation, cross-device booking synchronization, or emergency monitoring.
- Store only fictional information during judging. QR passes contain opaque references, never emergency contacts or waiver contents.
- Price estimates can change before closing. Locked amounts never increase after another reservation expires. Organizer cancellation refunds paid bookings in the simulation.
- Keep test evidence and AI-process claims grounded in completed work.
