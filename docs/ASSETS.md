# Assets and dependencies

## Original work
Application source, domain rules, tests, visual composition, interface copy, favicon, and collaboration documents were authored for this hackathon using Codex. No application source or assets were copied from the older Akyat repository.

## Trail imagery
The app uses seven photos from Marti’s supplied Akyat Mountains folder and an original generated hero from the supplied minimal design handoff. See [PHOTO-SELECTION.md](PHOTO-SELECTION.md) for exact file mapping and provenance limitations. Contour studies remain only as load-error fallbacks.

Visual inspiration: https://akyat-ph.vercel.app/ was inspected as a rendered website. No old source or assets were copied.

## Libraries and fonts
- React / React DOM: interface rendering.
- Vite: development and static build.
- Lucide React: icons.
- qrcode: QR generation.
- jsQR: QR decoding.
- GSAP + ScrollTrigger: entrance, scroll, and price animations.
- Archivo (with an inherited DM Sans fallback stylesheet): Google Fonts stylesheet, with system sans-serif fallback.

The hackathon prohibits reuse of existing app code. If its official rules also restrict dependencies or stock imagery, the team must confirm that from the event brief; that brief has not been supplied in this chat.
